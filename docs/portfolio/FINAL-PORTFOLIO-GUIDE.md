# DevOpsHub Portfolio Guide

## Positioning
Enterprise engineering operations platform built with ASP.NET Core, EF Core, React and TypeScript.

## Demo narrative
1. Sign in with the seeded demo account.
2. Show workspace RBAC and Kanban delivery flow.
3. Trigger a pipeline and inspect logs.
4. Open an incident and demonstrate SLA signals.
5. Review code, documentation, analytics and approval workflows.

## Interview themes
Clean Architecture, JWT security, SignalR, auditability, local-first zero-cost deployment, testing, Docker, CI/CD and scalable module boundaries.
