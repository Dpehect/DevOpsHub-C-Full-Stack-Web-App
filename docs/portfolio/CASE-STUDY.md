# DevOpsHub Portfolio Case Study

## Problem
Engineering teams often split planning, deployments, incidents, documentation and operational analytics across disconnected tools.

## Solution
DevOpsHub is a zero-cost, self-hosted engineering operations platform built with ASP.NET Core and React. It combines project delivery, repository simulation, pipelines, incidents, real-time notifications, observability, documentation, analytics and administration.

## Technical highlights
- Clean Architecture and modular monolith
- EF Core with SQLite and seeded demo data
- JWT authentication, refresh tokens and role-based authorization
- SignalR real-time notifications
- Rate limiting, security headers and audit logging
- Unit/integration test foundations and CI quality gates
- Multi-stage Docker builds and one-command local startup
